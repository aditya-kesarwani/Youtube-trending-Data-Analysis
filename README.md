# YouTube Trending Data Analysis

This project analyzes YouTube trending video data using Python, Pandas, NumPy, and Matplotlib.

## Features

- Excel dataset handling
- Data analysis using NumPy
- Trending videos analysis
- Scatter plot visualization
- Views and likes comparison

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Excel

## Files Included

- youtube_trending_dataset.xlsx
- youtube_data_cleaning.py
- cleaned_youtube_dataset.xlsx
- youtube_visualization.py
- youtube_scatter_plot.png

## Output

The project generates:
- Cleaned dataset
- Views analysis
- Scatter plot visualization
